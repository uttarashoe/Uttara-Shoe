# উত্তরা সুজ — Supabase সেটআপ

`schema.sql` এবং ওয়েব অ্যাপের সংযোগ-কোড প্রস্তুত। SQL নতুন Supabase প্রজেক্ট `gabzmhrgdwzquejdmtza`-এ চালানো হয়েছে। ডেটাবেসে লগইন-প্রোফাইল, ভূমিকা, রেকর্ডের প্রবেশাধিকার এবং বিক্রির নিরাপত্তা-নিয়ম তৈরি হয়েছে।

## নিরাপত্তার নিয়ম

- প্রত্যেক সদস্য নিজের ইমেইল দিয়ে লগইন করবেন। নতুন অ্যাকাউন্ট প্রথমে নিষ্ক্রিয় থাকবে; ম্যানেজার অনুমোদন না করা পর্যন্ত ব্যবসার ডেটা দেখা বা বদলানো যাবে না।
- শুধু ম্যানেজার সদস্য সক্রিয়/নিষ্ক্রিয় করতে, ভূমিকা ও পৃষ্ঠা-অনুমতি দিতে এবং সর্বোচ্চ ছাড় ঠিক করতে পারবেন।
- ম্যানেজার পণ্যের দাম, পণ্য/কাঁচামালের মজুত, উৎপাদন ও ক্রয় রেকর্ড নিয়ন্ত্রণ করবেন।
- বিক্রয় সদস্য বিক্রি জমা দিতে ও নিজের বিক্রির বাকি আদায় নথিভুক্ত করতে পারবেন। ডেটাবেস দাম ও অনুমোদিত ছাড় যাচাই করে একই লেনদেনে মজুত কমাবে। অন্য সদস্যের বিক্রি পরিবর্তন করা যাবে না।
- বিক্রয় সদস্যের কাছ থেকে পণ্যের ক্রয়খরচ ও মুনাফার তথ্য লুকানো থাকবে।
- ডেটাবেসের Row Level Security এসব নিয়ম কার্যকর করবে; HTML-এর বোতাম/পৃষ্ঠা লুকানোকে নিরাপত্তা হিসেবে ধরা হয়নি।

## প্রথম ম্যানেজার চালু করা

1. ডেটাবেস সেটআপ সম্পন্ন। Supabase Authentication → Users-এ প্রথম ম্যানেজারের Auth account তৈরি করুন, অথবা প্রকাশিত ওয়েব অ্যাপের লগইন পর্দা থেকে সাইন আপ করুন। নতুন অ্যাকাউন্ট যাচাই/তৈরি হলেও শুরুতে নিষ্ক্রিয় থাকবে।
2. SQL Editor-এ নিচের কমান্ডে `manager@example.com`-এর জায়গায় ম্যানেজারের ইমেইল বসিয়ে একবার চালান:

```sql
update public.app_members
set role = 'manager', active = true, max_discount = 100
where lower(email) = lower('manager@example.com');
```

3. ম্যানেজার অ্যাপ থেকে লগইন করে সদস্যদের সক্রিয় করবেন, অনুমতি দেবেন এবং ছাড়ের সীমা ঠিক করবেন।
4. আগের অ্যাপের বর্তমান ডেটা থাকা ব্রাউজার থেকে JSON backup নামিয়ে ম্যানেজার হিসেবে নতুন অ্যাপে import করুন। ব্রাউজারের `localStorage` ডেটা HTML ফাইলে থাকে না, তাই backup আলাদা করে নিতে হবে।
